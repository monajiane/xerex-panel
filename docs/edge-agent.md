# Xerex Edge Agent Protocol

The Edge Agent (Go binary, Phase 4) runs on each edge server and bridges
the gap between the **Xerex Panel** and the local **Nginx** instance.

## Authentication

Every request from the agent to the panel includes:

```
Authorization: Bearer xerx_<48 chars>
```

The token is generated by the panel when the edge server is created and
is bound to a specific `EdgeServer` row.

## Endpoints

### `GET /api/agent/config`

Returns the full set of proxy rules assigned to this edge.

Response:
```json
{
  "edge": { "id": 1, "uuid": "...", "name": "IR-Edge-1", "hostname": "edge1.ir.example.com", "capabilities": ["http2"] },
  "rules": [
    {
      "id": 42,
      "uuid": "...",
      "domain": "example.com",
      "type": "http",
      "path": "/",
      "path_match_type": "prefix",
      "listen_port": 443,
      "force_https": true,
      "http2_enabled": true,
      "http3_enabled": false,
      "priority": 100,
      "weight": 100,
      "headers_request":  { "X-Real-IP": "$remote_addr" },
      "headers_response": { "X-Frame-Options": "DENY" },
      "cache_rules": null,
      "rate_limit":  null,
      "access_rules": null,
      "origin": {
        "url": "http://198.51.100.10:8080",
        "host": "198.51.100.10",
        "port": 8080,
        "protocol": "http",
        "weight": 100,
        "max_fails": 3,
        "fail_timeout": 10,
        "health_check_path": "/health",
        "connect_timeout": 5,
        "read_timeout": 60,
        "send_timeout": 60
      }
    }
  ],
  "generated_at": "2026-07-29T10:00:00+00:00"
}
```

The agent should:
1. Compute the SHA-256 hash of each rule's generated config
2. Compare with its local cache
3. If different, render and write to `/etc/nginx/conf.d/xerex-<id>.conf`
4. Run `nginx -t` then `nginx -s reload`

### `POST /api/agent/telemetry`

Periodic metrics (every 30s recommended).

```json
{
  "agent_version": "0.1.0",
  "cpu_usage": 23.5,
  "ram_usage": 41.2,
  "disk_usage": 12.0,
  "bandwidth_in_bytes": 1024000,
  "bandwidth_out_bytes": 5120000,
  "active_connections": 142,
  "requests_per_second": 850,
  "capabilities": ["http2", "http3", "websocket"]
}
```

Bulk upload of access logs (max 1000 per request, every 10s).

```json

      "domain_id": 1,
      "proxy_rule_id": 42,

      "scheme": "https",

      "host": "example.com",
      "path": "/path",
      "response_code": 200,
      "bytes_sent": 1234,
      "bytes_received": 567,
      "request_time_ms": 45,
      "upstream_time_ms": 38,
      "client_ip": "1.2.3.4",
      "user_agent": "Mozilla/5.0...",
      "referer": "https://google.com",
      "protocol": "HTTP/2",
      "cached": false,
      "cache_status": "MISS",
      "logged_at": "2026-07-29T10:00:00Z"
    }
```

Response: `{ "inserted": 1 }`

### `POST /api/agent/health`

Submit a health check result.

```json
{
  "check_type": "http",
  "target": "http://198.51.100.10:8080/health",
  "status": "up",   // up | down | degraded | timeout
  "response_code": 200,
  "latency_ms": 42,
  "origin_server_id": 1,
  "error": null
}
```

## Long Polling vs Push

The agent can either:

1. **Poll** `GET /api/agent/config` every 30s (default)
2. **Subscribe** to a WebSocket push channel (planned for Phase 4)

The polling response includes the `generated_at` timestamp so the agent
can skip updates it has already applied.

## TLS

Agents **MUST** use TLS 1.2+ to talk to the panel. The certificate can
be either:

- A public CA certificate (e.g., Let's Encrypt on the panel domain)
- A self-signed cert whose fingerprint was pre-registered on the edge row
  (`agent_tls_fingerprint`)

## Local Filesystem Layout

```
/etc/xerex/
├── agent.yaml            # Agent config (server URL, token, TLS settings)
├── cache/
│   ├── config-hash.txt   # SHA-256 of last applied config
│   └── last-pull.txt     # ISO timestamp of last poll
└── logs/
    └── agent.log         # Rotated agent log

/etc/nginx/
├── nginx.conf            # Main config (managed by agent)
└── conf.d/
    ├── 000-xerex-base.conf
    ├── xerex-rule-42.conf
    ├── xerex-rule-87.conf
    └── ...

/var/log/xerex/
└── access.log            # Shipped to panel via POST /agent/traffic
```
